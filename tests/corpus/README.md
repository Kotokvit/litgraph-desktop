# Тестовый корпус LitGraph POLER

Дата создания: 2026-08-09
Назначение: Таргетированные тестовые тексты для разработки и проверки алгоритмов POLER[Ψ]

## Принципы

В отличие от большого `kasiopia.md` (1.1 МБ), этот корпус содержит **короткие, специально сконструированные тексты**, каждый из которых нацелен на проверку конкретного оператора или фазы POLER. Это даёт:

1. **Известные ожидаемые результаты** — каждый тест имеет annotированный expected output
2. **Быструю итерацию** — тексты 3–8 КБ обрабатываются за миллисекунды, не секунды
3. **Изоляцию фич** — можно тестировать один алгоритм, не затрагивая остальные
4. **Регрессионное тестирование** — после изменения математики POLER сразу видно, что сломалось

## Структура

| Файл | Размер | Что тестирует | POLER-оператор |
|---|---|---|---|
| `01_conflict_scene.md` | ~4 КБ | Конфликт с явными SVO «агрессор→жертва» | J (ток/власть) |
| `02_aliases_test.md` | ~3 КБ | Алиасы одного персонажа (Алексей = Лёша = Нулевой Фактор) | Π_Λ + coreference |
| `03_isolated_character.md` | ~3 КБ | Персонаж появляется и исчезает без влияния на граф | Observer-Kill (HΨ=0) |
| `04_multi_chapter.md` | ~6 КБ | 3 главы с разной тематикой и эмоциональной окраской | ε (энергия/энтропия), R[n] (резонанс) |
| `05_duplicate_scenes.md` | ~4 КБ | Две сцены с идентичным смыслом, разными словами | F (свободная энергия), SBERT-сходство |

## Использование

### Быстрый тест NER + SVO
```bash
cd /home/z/my-project/litgraph-desktop
python src-tauri/python/ner_extract.py tests/corpus/01_conflict_scene.md
python src-tauri/python/svo_extract.py tests/corpus/01_conflict_scene.md
```

### Тест POLER-физики
```bash
python src-tauri/python/poler_entities.py tests/corpus/01_conflict_scene.md
```

### Регрессионный прогон по всем тестам
```bash
for f in tests/corpus/*.md; do
  echo "=== $(basename $f) ==="
  python src-tauri/python/poler_entities.py "$f" --json > "tests/corpus/results/$(basename $f .md).json"
done
```

## Ожидаемые результаты (Expected Outputs)

Каждый тестовый файл содержит блок `<!-- EXPECTED: ... -->` в конце с описанием того, что должен показать POLER-анализ. Эти аннотации используются в автоматических тестах.

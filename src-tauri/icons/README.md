# Иконки приложения

Сюда нужно положить иконки для Tauri-сборки:

- `32x32.png`
- `128x128.png`
- `128x128@2x.png` (256x256)
- `icon.icns` (для macOS — но мы собираем под Linux, можно пустой)
- `icon.ico` (для Windows — но мы собираем под Linux, можно пустой)

## Как создать

### Через Tauri CLI (рекомендуется)

```bash
# Из корня проекта
cargo tauri icon path/to/source-icon-1024x1024.png
```

Это автоматически сгенерирует все нужные размеры.

### Вручную

1. Создать PNG 1024x1024 с логотипом LitGraph
2. Уменьшить до 32x32, 128x128, 256x256, 512x512
3. Конвертировать в .ico (через `convert icon.png icon.ico` в ImageMagick)
4. Конвертировать в .icns (через `png2icns`)

## Источник логотипа

Логотип из превью-прототипа — перо в градиенте от янтарного к тёмно-серому
(см. docs/screenshots/ для примера UI).

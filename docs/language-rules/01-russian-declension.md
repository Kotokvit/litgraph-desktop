## 1. Шість відмінків

| # | Відмінок | Російська | Питання | Функція |
|---|----------|-----------|---------|---------|
| 1 | Nominative | Именительный | кто? что? | підмет |
| 2 | Genitive | Родительный | кого? чего? | приналежність, "з" + noun |
| 3 | Dative | Дательный | кому? чему? | непрямий об'єкт, "to" + noun |
| 4 | Accusative | Винительный | кого? что? | прямий об'єкт |
| 5 | Instrumental | Творительный | кем? чем? | інструмент, "with" + noun |
| 6 | Prepositional | Предложный | о ком? о чём? | з прийменником (в, на, о) |

**Анімативність** критична для Accusative:
- для одух. (люди, тварини): Accusative = Genitive
- для неодух. (речі): Accusative = Nominative

Це важливо для `KILL(a, p, t)`: "убил Петра" → `Петра` це Accusative одух. =
Genitive від "Пётр".

## 2. Три типи відмінювання

### 2.1. Перше відмінювання (I)

**Іменники на -а / -я**, переважно жіночого роду, але також чоловічі (папа,
дядя) та спільного роду (задира, соня).

| Відмінок | -а (твердий) | -я (м'який) | -ия |
|----------|--------------|-------------|-----|
| Nom | рабо́та | ба́ня | ли́ния |
| Gen | рабо́ты | ба́ни | ли́нии |
| Dat | рабо́те | ба́не | ли́нии |
| Acc | рабо́ту | ба́ню | ли́нию |
| Inst | рабо́той | ба́ней | ли́нией |
| Prep | рабо́те | ба́не | ли́нии |

**Множина**:

| Відмінок | -а | -я | -ия |
|----------|----|----|-----|
| Nom | рабо́ты | ба́ни | ли́нии |
| Gen | рабо́т | ба́нь | ли́ний |
| Dat | рабо́там | ба́ням | ли́ниям |
| Acc (неодух.) | рабо́ты | ба́ни | ли́нии |
| Acc (одух.) | рабо́т | ба́нь | ли́ний |
| Inst | рабо́тами | ба́нями | ли́ниями |
| Prep | рабо́тах | ба́нях | ли́ниях |

**Правила орфографії**:
- після шиплячих (ж, ч, ш, щ) і задньоязикових (г, к, х): `и` замість `ы`
  (кни́га → кни́ги, не *кни́гы*)
- після шиплячих під наголосом: `о`, без наголосу: `е`
- після м'якого приголосного під наголосом: `ё`, без наголосу: `е`

### 2.2. Друге відмінювання (II) — чоловічі

**Чоловічі іменники на приголосний, -й, -ь**.

| Відмінок | ∅ (твердий) | -й | -ь |
|----------|-------------|-----|-----|
| Nom | стол | герой | гость |
| Gen | стола́ | геро́я | го́стя |
| Dat | столу́ | геро́ю | го́стю |
| Acc (неодух.) | стол | геро́я | го́сть |
| Acc (одух.) | стола́ | геро́я | го́стя |
| Inst | столо́м | геро́ем | го́стем |
| Prep | столе́ | герое́ | го́сте |

**Множина**:

| Відмінок | ∅ | -й | -ь |
|----------|----|----|----|
| Nom | столы́ | геро́и | го́сти |
| Gen | столо́в | геро́ев | госте́й |
| Dat | стола́м | геро́ям | гостя́м |
| Acc (неодух.) | столы́ | геро́и | го́сти |
| Acc (одух.) | столо́в | геро́ев | госте́й |
| Inst | стола́ми | героя́ми | гостя́ми |
| Prep | стола́х | героя́х | гостя́х |

**Бігла голосна** (важливо!):
- деякі чоловічі на -ел, -ер, -ец втрачають "е"/"о" при відмінюванні:
  - оте́ц → отца́, отцу́, отцо́м, отце́ (Gen/Dat/Inst/Prep без "е")
  - кузне́ц → кузнеца́
  - Palestinians → палестинца
  - прода́вец → продавца́

Це правило **відсутнє** в поточному `generate_russian_declensions`. Його треба
додати: якщо закінчення -ец, -ек, -ёк, -ел → відкинути "е/ё" перед закінченням.

### 2.3. Друге відмінювання (II) — середні

**Середні іменники на -о / -е**.

| Відмінок | -о (твердий) | -е (м'який) | -ие |
|----------|--------------|-------------|-----|
| Nom | сло́во | мо́ре | зда́ние |
| Gen | сло́ва | мо́ря | зда́ния |
| Dat | сло́ву | мо́рю | зда́нию |
| Acc | сло́во | мо́ре | зда́ние |
| Inst | сло́вом | мо́рем | зда́нием |
| Prep | сло́ве | мо́ре | зда́нии |

### 2.4. Третє відмінювання (III)

**Жіночі іменники на -ь** (м'який знак).

| Відмінок | Однина | Множина |
|----------|--------|---------|
| Nom | ночь | но́чи |
| Gen | но́чи | ноче́й |
| Dat | но́чи | ноча́м |
| Acc | ночь | но́чи |
| Inst | но́чью | ноча́ми |
| Prep | но́чи | ноча́х |

### 2.5. Розно-склоняємі (особливі)

7 слів на -мя (час, ім'я, плем'я, etc.) і `путь` (шлях):

| Відмінок | вре́мя | путь |
|----------|--------|------|
| Nom | вре́мя | путь |
| Gen | вре́мени | пути́ |
| Dat | вре́мени | пути́ |
| Acc | вре́мя | путь |
| Inst | вре́менем | путём |
| Prep | вре́мени | пути́ |

## 3. Розширення `generate_russian_declensions` — конкретний план

### 3.1. Поточний алгоритм (5 правил)

```rust
pub fn generate_russian_declensions(name: &str) -> Vec<String> {
    // 1. -ия → -ии, -ию, -ией
    // 2. -а  → -ы, -и, -е, -у, -ой
    // 3. -я  → -и, -е, -ю, -ей
    // 4. -й  → -я, -ю, -ем, -е
    // 5. -ь  → -я, -ю, -ем, -е
    // 6. consonant → -а, -у, -ом, -е, -ы
    // Special: Пётр, Лев
}
```

### 3.2. Пропоноване розширення (15+ правил)

```rust
pub fn generate_russian_declensions_v2(name: &str) -> Vec<CaseForms> {
    // Покриває всі 3 відмінювання, 2 числа, анімативність
    // + біглі голосні (отец, кузнец, продавец)
    // + по батькові (Иванович, Ивановна)
    // + прізвища на -ов/-ев/-ин, -ский, -ий
    // + топоніми
}
```

Див. повну таблицю в [`raw/ru-cases-wiki.txt`](raw/ru-cases-wiki.txt) (розділи
"First declension", "Second declension", "Third declension").

### 3.3. Скільки форм треба генерувати

| Тип | Форм на слово |
|------|---------------|
| Звичайне ім'я (чоловіче, однина) | 6 (усі відмінки) |
| Звичайне ім'я (жіноче, однина) | 6 |
| З анімативністю (чоловіче) | 7 (Acc має 2 варіанти) |
| З множиною | 12-14 |
| З біглою голосною | +1 варіант |
| По батькові | 12 (однина + множина) |
| Прізвище на -ов | 12 |

Для роману з 50 персонажами ~600 форм замість ~250 зараз.

## 4. Анімативність — критерії

**Одух. (Acc = Gen)**:
- всі люди (імена, професії, національності)
- тварини (ведмідь, кіт, собака)
- іграшки у вигляді людей (лялька, матрьошка)
- міфологічні істоти (дракон, русалка)

**Неодух. (Acc = Nom)**:
- рослини (дерево, квітка)
- предмети (стіл, книга)
- абстрактні (любов, час)
- колективи (народ, натовп — іноді одух.)

**Важливо**: `"убил Петра"` → Пётр одух. → Acc = Gen → форма "Петра".
`"разбил окно"` → вікно неодух. → Acc = Nom → форма "окно".

Це правило в коді **відсутнє**. Зараз `target_for_action()` бере `object_lemma`
як є, без перевірки форми. Додати: якщо об'єкт KILL — перевірити, що форма у
Genitive/Accusative-animate, інакше спробувати згенерувати.

## 6. Тести, які треба додати

```rust
#[test]
fn test_animacy_accusative_genitive_for_kill() {
    // "убил Петра" — Accusative = Genitive
    let decls = generate_russian_declensions_v2("Пётр");
    assert!(decls.contains_case(Case::Genitive, "петра"));
    assert!(decls.contains_case(Case::Accusative, "петра"));
}

#[test]
fn test_inanimacy_accusative_nominative_for_window() {
    // "разбил окно" — Accusative = Nominative
    let decls = generate_russian_declensions_v2("окно");
    assert!(decls.contains_case(Case::Accusative, "окно"));
}

#[test]
fn test_fleeting_vowel_otec() {
    let decls = generate_russian_declensions_v2("отец");
    assert!(decls.contains_form("отца"));
    assert!(decls.contains_form("отцу"));
    // "отеца" — НЕ правильно
    assert!(!decls.contains_form("отеца"));
}

#[test]
fn test_plurals() {
    let decls = generate_russian_declensions_v2("Иван");
    assert!(decls.contains_plural("иваны"));   // Nom pl
    assert!(decls.contains_plural("иванов"));  // Gen pl
    assert!(decls.contains_plural("иванам"));  // Dat pl
}
```

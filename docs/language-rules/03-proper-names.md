# 03. Імена власні: імена, по батькові, прізвища

> Канонічний довідник для розширення `generate_russian_declensions()` і
> створення `generate_ukrainian_declensions()`. Імена власні мають
> специфічні правила відмінювання, що відрізняються від загальних.
>
> Джерело: [Gramota.ru: Склонение фамилий](https://gramota.ru/biblioteka/spravochniki/pismovnik/kak-sklonyat-sostavnye-sushchestvitelnye),
> [Slovnyk.ua](https://slovnyk.ua),
> [Wikipedia](https://en.wikipedia.org/wiki/Russian_declension).
> Сирі тексти в [`raw/ru-declension-gramota.txt`](raw/ru-declension-gramota.txt).

## 1. Російські імена

### 1.1. Повне ім'я + коротка форма + здрібніла

| Повне | Коротка | Здрібніла |
|-------|---------|-----------|
| Иван | Ваня | Ванюша, Ванечка, Ванятка |
| Пётр | Петя | Петенька, Петюша, Петруша |
| Алексей | Лёша | Лёшенька, Лёшенька |
| Дмитрий | Дима | Димочка, Димуля |
| Николай | Коля | Коленька, Колюня |
| Александр | Саша | Сашенька, Сашуля |
| Сергей | Серёжа | Серёженька |
| Андрей | Андрюша | Андрюшенька |
| Михаил | Миша | Мишенька, Мишутка |
| Владимир | Вова | Вовочка, Вовик |

Для LitGraph: **кожна здрібніла форма = alias того самого персонажа**.
Поточний код бере aliases з `node.data.meta.aliases`, але не генерує їх
автоматично. Можна додати словник "повне → здрібнілі".

| Пётр | -р (приг) | II-hard, бігла | Пётр | Петра | Петру | Петра | Петром | Петре |
| Лев | -в (приг) | II-hard, бігла | Лев | Льва | Льву | Льва | Львом | Льве |
| Олег | -г (приг) | II-hard | Олег | Олега | Олегу | Олега | Олегом | Олеге |
| Алексей | -й | II-soft | Алексей | Алексея | Алексею | Алексея | Алексеем | Алексе |
| Игорь | -ь | II-soft | Игорь | Игоря | Игорю | Игоря | Игорем | Игоре |
| Илья | -я | I | Илья | Ильи | Илье | Илью | Ильёй | Илье |

## 3. Російські прізвища

### 3.1. На -ов / -ев / -ин (найчастіші)

**Чоловічі** (особливе відмінювання, гібрид іменника + прикметника):

| Прізвище | Nom | Gen | Dat | Acc | Inst | Prep |
|----------|-----|-----|-----|-----|------|------|
| Иванов | Иванов | Иванова | Иванову | Иванова | Ивановым | Иванове |
| Синицын | Синицын | Синицына | Синицыну | Синицына | Синицыным | Синицыне |
| Кольцов | Кольцов | Кольцова | Кольцову | Кольцова | Кольцовым | Кольцове |

**Увага**: Inst = -ым (як прикметник), а не -ом (як іменник).
**Увага**: Prep = -е (як іменник), а не -ом (як прикметник).

**Жіночі** (тільки Nom відрізняється):

| Прізвище | Nom | Gen | Dat | Acc | Inst | Prep |
|----------|-----|-----|-----|-----|------|------|
| Иванова | Иванова | Ивановой | Ивановой | Иванову | Ивановой | Ивановой |
| Синицына | Синицына | Синицыной | Синицыной | Синицыну | Синицыной | Синицыной |

**Множина**:

| Прізвище | Nom | Gen | Dat | Acc | Inst | Prep |
|----------|-----|-----|-----|-----|------|------|
| Ивановы | Ивановы | Ивановых | Ивановым | Ивановых | Ивановыми | Ивановых |

### 3.2. На -ский / -цкий / -ый / -ой (прикметникові)

Відмінюються як прикметники:

| Прізвище | Nom | Gen | Dat | Acc | Inst | Prep |
|----------|-----|-----|-----|-----|------|------|
| Достоевский | Достоевский | Достоевского | Достоевскому | Достоевского | Достоевским | Достоевском |
| Толстой | Толстой | Толстого | Толстому | Толстого | Толстым | Толстом |

### 3.3. На -ый / -ий (українські прізвища в рос. контексті)

| Прізвище | Nom | Gen | Dat | Inst | Prep |
|----------|-----|-----|-----|------|------|
| Ковалив | Ковалив | Ковалива | Коваливу | Коваливым | Коваливе |

### 3.4. Незмінювані прізвища

Прізвища на -о, -е, -и, -ых, -их, -аго, -яго, -ово, -ино **не відмінюються**:

- Дюрренматт, Гюго, Шевченко, Кобо, Бальзак (значить "Абдулаєв, Дурново, Боско")
- Че́хов (давня форма, не відмінюється в Spoken, відмінюється в literary)
- Сухих, Чёрных, Бельских, Долгих (s-типу)

### 3.5. Іноземні прізвища на приголосний

**Чоловічі** відмінюються: Шмидт → Шмидта, Шмидту.
**Жіночі** НЕ відмінюються: Анна Шмидт (не *Шмидты*).

Це важливо для LitGraph: `entity_resolver` повинен знати стать носія прізвища,
щоб правильно генерувати форми.

| Петрівна | Петрівна | Петрівни | Петрівні | Петрівну | Петрівною | Петрівні | Петрівно |

### 4.4. Прізвища

**На -енко** (найчастіші, **незмінювані в українській**):

Шевченко, Гончаренко, Ткаченко — у всіх відмінках форма "Шевченко".

**Але в російській** вони відмінюються: Шевченко → Шевченки, Шевченку, Шевченком.

Для LitGraph: визначити мову тексту перед застосуванням правил.

**На -ський / -цький** (відмінюються як прикметники):

| Прізвище | Nom | Gen | Dat | Inst | Loc |
|----------|-----|-----|-----|------|-----|
| Кравецький | Кравецький | Кравецького | Кравецькому | Кравецьким | Кравецькому |

**На -ів / -їв**:

| Прізвище | Nom | Gen | Dat | Inst | Loc |
|----------|-----|-----|-----|------|-----|
| Петренко | Петренко | Петренка | Петренку | Петренком | Петренку |
| Ковалив | Ковалив | Ковалива | Коваливу | Киваливом | Коваливові |

## 5. План реалізації

### 5.1. Структура даних

```rust
pub struct ProperName {
    pub canonical: String,           // Іван
    pub full_form: Option<String>,   // Іоанн (церковна форма)
    pub short_forms: Vec<String>,    // Ваня
    pub diminutives: Vec<String>,    // Ванюша, Ванечка
    pub patronymic_male: Option<String>,   // Іванович
    pub patronymic_female: Option<String>, // Іванівна
    pub surname_male: Option<String>,      // Іванов
    pub surname_female: Option<String>,    // Іванова
    pub gender: Gender,
    pub language: Language,
}
```

### 5.2. Словник найчастіших імен

Створити JSON-словник 500+ російських і 300+ українських імен з усіма формами:
- `data/names-ru.json`
- `data/names-uk.json`

Для кожного імені:
- канонічна форма
- стать
- здрібнілі (3-5 варіантів)
- по батькові (якщо чоловіче)

### 5.3. Алгоритм розпізнавання

```rust
pub fn resolve_proper_name(word: &str, lang: Language) -> Option<ProperNameId> {
    // 1. Точний пошук у словнику канонічних форм
```

## 6. Тести

```rust
#[test]
fn test_russian_surname_ivanov_male() {
    let decls = generate_russian_declensions_v2("Иванов");
    assert!(decls.contains_form("Иванова"));   // Gen
    assert!(decls.contains_form("Иванову"));   // Dat
    assert!(decls.contains_form("Ивановым"));  // Inst (не "Ивановом"!)
    assert!(decls.contains_form("Иванове"));   // Prep
}

#[test]
fn test_russian_surname_ivanova_female() {
    let decls = generate_russian_declensions_v2("Иванова");
    assert!(decls.contains_form("Ивановой"));  // Gen (не "Ивановы"!)
}

#[test]
fn test_patronymic_ivanovich() {
    let decls = generate_russian_declensions_v2("Иванович");
    assert!(decls.contains_form("Ивановича"));   // Gen
    assert!(decls.contains_form("Ивановичем"));  // Inst
}

#[test]
fn test_ukrainian_name_with_double_dative() {
    let decls = generate_ukrainian_declensions("Іван");
    assert!(decls.contains_form("Іванові"));  // Dat варіант 1
    assert!(decls.contains_form("Івану"));    // Dat варіант 2
}

#[test]
fn test_ukrainian_surname_shevchenko_ukrainian() {
    // В українській незмінюване
    let decls = generate_ukrainian_declensions("Шевченко");
    assert_eq!(decls.len(), 1);  // Тільки Nom
}

#[test]
fn test_ukrainian_surname_shevchenko_russian() {
    // В російській відмінюється
    let decls = generate_russian_declensions_v2("Шевченко");
    assert!(decls.contains_form("Шевченко"));  // Nom
    assert!(decls.contains_form("Шевченки"));  // Gen? — НІ! Gen = "Шевченко"
    // А от Dat = "Шевченку", Inst = "Шевченком"
    assert!(decls.contains_form("Шевченку"));
    assert!(decls.contains_form("Шевченком"));
}
```

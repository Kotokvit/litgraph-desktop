# 02. Українське відмінювання іменників

> Канонічний довідник для реалізації `generate_ukrainian_declensions()` (поки
> відсутня в коді). Українська має 7 відмінків (на 1 більше за російську — є
> кличний) і 4 типи відмінювання (на 1 більше за російську).
>
> Джерело: [Wikipedia: Ukrainian declension](https://en.wikipedia.org/wiki/Ukrainian_declension)

> [`raw/uk-grammar-wiki.txt`](raw/uk-grammar-wiki.txt),
> [`raw/uk-declension-ukrgramota.txt`](raw/uk-declension-ukrgramota.txt).

## 1. Сім відмінків

| # | Відмінок | Українська | Питання | Функція |
|---|----------|------------|---------|---------|
| 1 | Nominative | Називний | хто? що? | підмет |
| 2 | Genitive | Родовий | кого? чого? | приналежність |
| 3 | Dative | Давальний | кому? чому? | непрямий об'єкт |
| 4 | Accusative | Знахідний | кого? що? | прямий об'єкт |
| 5 | Instrumental | Орудний | ким? чим? | інструмент |
| 6 | Locative | Місцевий | на кому? на чому? | місце |
| 7 | Vocative | Кличний | клич | звертання |

**Приклад**: `мова` (мова, мови, мові, мову, мовою, мові, мово).

**Анімативність** (як у російській):
- одух. (Acc = Gen): людину, кота
- неодух. (Acc = Nom): книгу, стіл

## 2. Чотири типи відмінювання

### 2.1. Перше відмінювання (I)

**Іменники на -а / -я**, переважно жіночого роду, рідше чоловічі (Микола, батько, тато).

**Однина**:

| Відмінок | Hard | Mixed | Soft (-ь) | Soft (-й) |
|----------|------|-------|-----------|-----------|
| Nom | -а | -а | -я | -я |
| Gen | -и | -і | -і | -ї |
| Dat | -і | -і | -і | -ї |
| Acc | -у | -у | -ю | -ю |
| Inst | -ою | -ею | -ею | -єю |
| Loc | -і | -і | -і | -ї |
| Voc | -о | -е | -е | -є |

**Множина**:

| Відмінок | Hard | Mixed | Soft (-ь) | Soft (-й) |
|----------|------|-------|-----------|-----------|
| Nom | -и | -і | -і | -ї |
| Gen | ∅ | ∅ | -ь | -й |
| Dat | -ам | -ам | -ям | -ям |
| Acc (неодух.) | -и / ∅ | -і / ∅ | -і / -ь | -ї / -й |
| Inst | -ами | -ами | -ями | -ями |
| Loc | -ах | -ах | -ях | -ях |
| Voc | -и | -і | -і | -ї |

**Приклади**:
- Hard: кава, церква, книга
- Mixed (після шиплячих): душа, хата (зміни о→е, и→і)
- Soft (-ь): земля, воля (мінус -я, +закінчення)
- Soft (-й): сім'я (зміни й→ї)

### 2.2. Друге відмінювання (II) — чоловічі

**Чоловічі іменники на приголосний, -ь, -й**.

**Однина**:

| Відмінок | Hard | Mixed | Soft (-ь) | Soft (-й) |
|----------|------|-------|-----------|-----------|
| Nom | ∅ | ∅ | -ь / ∅ | -й |
| Gen | -а / -у | -а / -у | -я / -ю | -я / -ю |
| Dat | -ові / -у | -еві / -у | -еві / -ю | -єві / -ю |
| Acc (неодух.) | ∅ / -а | ∅ / -а | -ь / -я | -й / -я |
| Inst | -ом | -ем | -ем | -єм |
| Loc | -ові / -і / -у | -еві / -і | -еві / -і | -єві / -ї |
| Voc | -у / -е | -е / -у | -ю | -ю |

**Вибір -а vs -у в Genitive**:
- **-а**: професії, імена людей, рослини, тварини, об'єкти, міста, одиниці виміру
- **-у**: хімічні елементи, матеріали, колективні, будівлі, абстрактні, установи

Приклад: "брат" → Gen = "брата" (людина); "камінь" → Gen = "каменю" (матеріал).

**Множина**:

| Відмінок | Hard | Mixed | Soft (-ь) | Soft (-й) |
|----------|------|-------|-----------|-----------|
| Nom | -и | -і | -і | -ї |
| Gen | -ів | -ів | -ів / -ей | -їв |
| Dat | -ам | -ам | -ям | -ям |
| Acc (одух.) | -и / -ів | -і / -ів | -і / -ів | -ї / -їв |
| Inst | -ами | -ами | -ями | -ями |
| Loc | -ах | -ах | -ях | -ях |

### 2.3. Друге відмінювання (II) — середні

**Середні на -о / -е / -я**.

| Відмінок | Hard (-о) | Mixed (-е) | Soft (-я) |
|----------|-----------|-------------|------------|
| Nom | село | море | поле |
| Gen | села | моря | поля |
| Dat | селу | морю | полю |
| Acc | село | море | поле |
| Inst | селом | морем | полем |
| Loc | селі | морі | полі |

### 2.4. Третє відмінювання (III)

**Жіночі на -ь або на шиплячий**.

| Відмінок | Однина | Множина |
|----------|--------|---------|
| Nom | ніч | ночі |
| Gen | ночі | ночей |
| Dat | ночі | ночам |
| Acc | ніч | ночі |
| Inst | ніччю | ночами |
| Loc | ночі | ночах |
| Voc | нче | ночі |

### 2.5. Четверте відмінювання (IV)

**Середні на -а / -я** (спільнослов'янське *ę): діти, теля, ім'я.

| Відмінок | Однина | Множина |
|----------|--------|---------|
| Nom | теля | телята |
| Gen | теляти | телят |
| Dat | теляті | телятам |
| Acc | теля | телята |
| Inst | телям | телятами |
| Loc | теляті | телятах |

## 3. Особливості, яких немає в російській

### 3.1. Кличний відмінок (Vocative)

Українська зберегла кличний відмінок, який російська втратила. Для LitGraph це
важливо для **діалогів**:

- "— Івану, піди сюди!" → Ivan це Vocative, не Nominative.
- "— Маріє, ти тут?" → Marie це Vocative від "Марія".

У Reasoning Engine треба: якщо `subject_lemma` в Vocative, і пропозиція —
репліка діалогу, то це не агент дії, а адресат. Зараз код не робить цієї
перевірки.

### 3.2. Парні форми

Українська зберегла залишки двоїни: "два стільці" ≠ "три стільці" ≠ "п'ять стільців".

Для LitGraph: коли `KILL(Ivan, 2, "Brother", "Brother")` — це окремий випадок,
що потребує окремого предиката (множинне вбивство). Зараз моделюється як 2
окремі події.

### 3.3. Чергування приголосних

В українській частіше, ніж у російській:
- к → ч (доки → дочці)
- г → ж (книга → книжці)
- х → ш (муха → мусі)

Це впливає на лематизацію: "дочці" треба розпізнати як Dative від "дочка".
Зараз `lemmatize_simple()` це не робить.

## 4. Алгоритм для `generate_ukrainian_declensions`

```rust
pub fn generate_ukrainian_declensions(name: &str) -> Vec<CaseForm> {
    let lc = name.trim().to_lowercase();
    let chars: Vec<char> = lc.chars().collect();
    let len = chars.len();
    if len < 2 { return vec![lc]; }

    // 1. Визначити тип (I, II-masc, II-neut, III, IV)
    let decl_type = match chars.last() {
        Some('а') | Some('я') => DeclType::First,
        Some('о') | Some('е') => DeclType::SecondNeut,
        Some('ь') => DeclType::Third, // або SecondMascSoft — за контекстом
        Some('й') => DeclType::SecondMascSoftJ,
        Some(c) if is_consonant(c) => DeclType::SecondMascHard,
        _ => DeclType::Indeclinable,
    };

    // 2. Визначити підгрупу (Hard / Mixed / Soft)
    let subgroup = detect_subgroup(&lc);

    // 3. Згенерувати всі 14 форм (7 однина + 7 множина)
    generate_forms(&lc, decl_type, subgroup)
}
```

### 4.1. Скільки форм треба генерувати

| Тип | Форм на слово |
|------|---------------|
| Звичайне ім'я (однина) | 7 |
| З множиною | 14 |
| З анімативністю | +1 варіант Acc |
| З -ові/-еві варіантами в Dat/Loc | +2 |

Для роману з 50 персонажів ~750 форм (проти ~250 в російській).

## 5. Особливі випадки (хардкодити)

| Канонічна форма | Особливість | Форми |
|-----------------|-------------|-------|
| мати | irregular | матері, матері, матір'ю |
| донька | irregular | доньки, доньці, доньку |
| час | незмінюване в однині? | (ні, рег.) |
| ім'я | IV відмінювання | імені, імені, ім'ям |
| дитя | IV відмінювання | дитяти, дитяті, дитям |
| Микола | чоловіче на -а (I відмін.) | Миколи, Миколі, Миколу |
| батько | чоловіче на -о (II відмін.) | батька, батькові, батьком |

## 6. Тести

```rust
#[test]
fn test_ukrainian_first_declension_hard() {
    let decls = generate_ukrainian_declensions("книга");
    assert!(decls.contains_form("книги"));   // Gen
    assert!(decls.contains_form("книзі"));   // Dat (чергування г→ж)
    assert!(decls.contains_form("книгу"));   // Acc
    assert!(decls.contains_form("книгою"));  // Inst
}

#[test]
fn test_ukrainian_vocative_for_dialogue() {
    let decls = generate_ukrainian_declensions("Іван");
    assert!(decls.contains_form("Іване"));   // Voc
}

#[test]
fn test_ukrainian_consonant_mutation() {
    // к → ч, г → ж, х → ш
    let decls_dochka = generate_ukrainian_declensions("дочка");
    assert!(decls_dochka.contains_form("дочці"));  // Dat
}
```

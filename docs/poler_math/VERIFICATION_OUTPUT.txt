  Q4.1-4.2: Projector P (coreference)
══════════════════════════════════════════════════════════════════════
  ✓ P^2 = P  (идемпотентность)

  ✓ R(θ) сохраняет J(2×2): R^T J R = J
  → Это пример корректного P: ортогональное вращение в плоскости J.

══════════════════════════════════════════════════════════════════════
  Q5.1: Negation operator N
══════════════════════════════════════════════════════════════════════

  --- 2D случай: тривиальное решение N = -I ---
  ✓ N=-I: N^2 = I
  ✓ N=-I: N^T = N
  ✓ N=-I: N J = -J
  ✓ N=-I: N A = -A  (НЕ подходит для «N A ≈ A»)

  --- 4D случай: блочно-диагональное решение ---
  N (4D) = diag(-I_2, I_2)
  J (4D) = diag(J_2, 0)
  A (4D) = diag(0, A_2)
  ✓ N (4D): N^2 = I
  ✓ N (4D): N^T = N
  ✓ N (4D): N J = -J
  ✓ N (4D): N A = A  (идеальный случай)

  --- Вывод ---
  Условия N J = -J И N A = A совместимы ТОЛЬКО при dim V ≥ 4
  с прямым разложением V = V_J ⊕ V_A.
  → POLER требует D ≥ 4 (на практике D ∈ {128, 256, 512}).
